# ISS-0019 Windows パス区切りの残存箇所・doclint 免除の広さ

## 事象（解決前）
1. `\` 区切りに依存する残存箇所（EP-50 で直したのは code_doc_lint のメッセージ 1 か所のみ）：pm・agent/lint の
   メッセージ、deliver/session の `inputs_of`（編集セッションの**指紋キー**）、ds/cli の 2 箇所。
2. doclint の案件領域免除が `fnmatch` で `*` が `/` を跨ぎ、Windows では大小無視で免除が OS により広がる。

## 対処
上の「解決」を参照（全 5 箇所を `.as_posix()`／conventions 規則5／`_covers` のセグメント境界一致＋`fnmatchcase`）。

## 積み残し（意図した判断・要再検討）
非 ID の案件領域パス（例 `work/README.md`）は doclint（案件領域として免除）と doc_source_lint（正規表現が
`work/(EP|T|E|INV)-…` の ID 形のみ）の両方をすり抜ける。現状 0 件・実害なし。塞ぐなら doclint 側で「`work/` 参照は
ID 形のときだけ免除、それ以外は実在検査」にするのが安いが、免除の意味論を分けることになる。意図した禁止は
ID 形で覆えているため今回は塞がない（増えたら再検討）。
