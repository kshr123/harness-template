> `tests/test_headless.py::test_chrome_locator_covers_mac_and_windows`）。

# ISS-0018 ヘッドレス実測テストの Chrome 探索

## 事象
依存ホバーの実測テスト（`tests/test_deliver_browser.py`）は実ブラウザ（Chrome）で `mouseenter` を発火させて
DOM を確かめる。ロケータ（`tests/_headless.py`）が macOS の既定パスしか見ておらず、Windows では Chrome を
見つけられず skip していた（＝その OS では「回っていないのに緑」の懸念）。

## 影響（解決前）
CI の Windows レグでだけ実測が skip され、ホバーの runtime 挙動が Windows では検査されていなかった
（ubuntu では実行・pass。データ側検査と JS 構文検査は常に回るので fail-open ではない）。

## 対処
ロケータを各 OS 対応にして、Chrome のある環境（Mac・CI の両 OS）では必ず走らせる（上の解決を参照）。
Chrome を持たない開発機だけ skip にフォールバックする（受け入れ基準のテストで探索構成の退行を止める）。
