# session（セッション運用・コンテキスト衛生）

## 着手前
- 該当タスク（`tasks/<id>.md`）と `AGENTS.md` だけを読む。全タスクは読まない。
- 粗い WBS のうち、着手が近いエピックだけを詳細化する（ローリングウェーブ）。

## 作業中
- 無関係なタスクに移るときは文脈を切り替える（/clear 相当）。
- 2 回直して駄目なら、いったん捨てて学びを反映した指示で再出発する。

## 完了前（セルフチェック）
- `uv run status` で STATUS.md を最新化したか。
- `uv run verify` が緑か（緑の証拠を示したか）。
- 範囲外を変更していないか。学び（friction 含む）を `learnings.md` に書いたか。

## 禁止事項
- 全タスク・不要な履歴を読み込んで文脈を膨らませない。
