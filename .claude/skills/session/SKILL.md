# session（作業の開始・終了と、読み込みすぎない工夫）

## 着手前
- その単位（`work/…/item.md` またはファイル）と `AGENTS.md` だけを読む。全単位は読まない。
- 全体の見出し（エピック）のうち、着手が近いものだけを詳しく分解する（近い作業だけ先に）。

## 作業中
- 関係のないタスクに移るときは、いったん文脈を切り替える。
- 見つけた問題・リスク・疑問は `uv run issue new "<題名>" --kind bug|risk|question --found-in <単位ID>` でその場で起票する（対処は別タスク・黙って流さない。一覧は `uv run issue list`）。
- 2 回直しても駄目なら、いったん捨てて、分かったことを反映した指示でやり直す。

## 完了前（自分での確認）
- `uv run verify` にすべて成功したか（成功した証拠を示したか）。
- 頼まれた範囲の外を変更していないか。気づき（使いにくかった点を含む）を `docs/learnings.md` に書いたか。
- 進捗を見たいときだけ `uv run status`（生成物・コミットしない・完了条件ではない・DEC-0002）。

## してはいけないこと
- 全タスクや不要な履歴を読み込んで、読み込みすぎない。
