# implement（1 タスクずつ実装する）

## 手順
1. テストを先に書く（期待する入力と出力の組）。実行して、まだ失敗することを確かめる。
2. テストをコミットする（あとでテストを書き換えていないと分かるように）。
3. テストを変えずに、実装だけを直して成功させる。
4. `uv run verify` にすべて成功させ、成功した出力（証拠）を示す。

## してはいけないこと
- 頼まれた範囲の外を変えない（確信がなければ手を出さず報告する）。
- 起きない場合への備え・不要な作り込み・余分なテストを足さない。まず最小限で作る。
- テストの答えをハードコードしたり、テストを書き換えて成功させたりしない。
