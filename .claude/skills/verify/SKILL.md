# verify（完了判定）

## 共通の検証コマンド（実体は uv。make は使わない）
- `uv run verify` … まとめて検証（参照チェック＋STATUS 一致＋ruff＋mypy＋pytest）
- 段階を選ぶ：`uv run check --level fast|standard|full`

## 手順
1. `uv run status` で STATUS.md を最新にする（タスクを変えたら必ず）。
2. `uv run verify` を実行し、失敗したら理由を読む。
3. 実装だけ直して、すべて成功するまで回す（テストは緩めない・消さない）。
4. 成功した出力（証拠）を示す。すべて成功して初めて完了。

## してはいけないこと
- 証拠（成功した出力）なしに完了と宣言してはならない。
- テストを書き換えたり消したりして成功させてはならない。
- `STATUS.md` を手で編集してはならない（自動生成のファイル）。
