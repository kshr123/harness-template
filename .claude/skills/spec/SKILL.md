# spec（何を・なぜ作るかをまとめる）

## 手順
1. テンプレート `.harness/templates/spec.md` を読み、`tasks/<id>/SPEC.md` にまとめる。
2. 「目的」「受け入れ基準」「やらないこと（範囲の外）」「最後の確認手順」を埋める。
3. まだ決まっていない点は `[要確認: 質問]` と書いて残す（勝手に決めない）。人に確認する。

## してはいけないこと
- まだ決まっていない点を推測で埋めない。
- どう作るか（実装の詳しい方法）はここに書かない。それは plan で書く。
