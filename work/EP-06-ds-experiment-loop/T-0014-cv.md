# T-0014 交差検証 cv.py（歩く骨組みの背骨）

## 目的
実験ループの結線の背骨。fold 割当・添字対のリスト・run_cv を作り、以降の学習系・実験がこの上に載る。
設計は DESIGN.md B-3/B-4。分割は「添字対のリスト」で渡し、fold は split 層の表に保存して再現をデータで担保する。

## 受け入れ基準（テスト先行で）
- `make_folds(df,*,n_folds,seed,id_column,stratify_by)→(id,fold)表`：無層化は均等・層化はクラス均衡・同 (df,seed) は同表（純 numpy）。
- `fold_indices(df,folds)→[(train_idx,valid_idx)]`：id 集合が一致しないと失敗。存在する fold 値だけを回す（空 valid を作らない）。
- `holdout_indices(n_train,n_valid)`：固定分割＝要素1（train 先頭・valid 後ろ）。
- `CVResult(oof,oof_mask,fold_metrics,estimators,oof_metrics)`／`run_cv(estimator,x,y,splits,*,predict,metric_fn)`：fold ごとに `sklearn.base.clone` して train で fit（構造的漏れ防止）・valid 重複は失敗・oof_mask で未カバー黙認を回避・再現は estimator の random_state に委ねる。
- `SklearnLike` Protocol（fit/get_params）だけに依存し、モデルの具体を知らない（差し替えは estimator の交換）。※ DEC-0007 で自前 Trainer/FoldOutcome は不採用。
- 統合テスト（sklearn で）：DummyClassifier で run_cv の結線（OOF 全行・estimator 数・valid 重複検知）／Pipeline(StandardScaler,Dummy) の漏れ検知（train 部だけで fit）／make_folds→store.save(split)→load→fold_indices の往復＋再保存拒否。
- `uv run verify` 全成功。
