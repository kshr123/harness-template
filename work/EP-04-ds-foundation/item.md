# EP-04 データサイエンスの上乗せ（基盤）

## 目的
共通の開発基盤（作業単位の木・検証コマンド・設定）の上に、データサイエンス固有の基盤を載せる
（`04_データサイエンス.md`）。実験のループが回る前提として、まず基盤を固める：

- データを固定分割し、最終評価用のデータを学習・調整に使わない（データ漏れの防止）。
- 評価が指標を返し、設定の閾値で合否を判定する（評価の仕組み）。
- 特徴量の計算を共有コードに置き、単体テストの対象にする。

## 受け入れ基準
- 合成データを決め打ちの種から再現でき、固定分割が同じ種で必ず同じになる。
- 学習・調整用と最終評価用の分割に重複が無いことをテストが保証する。
- 評価が指標を返し、設定ファイルの閾値で合否（成功/失敗）を返す。
- `uv run verify` にすべて成功する。

## やらないこと（この段階の範囲外）
- 実験の記録ツール（MLflow）・データ/モデルの版管理（内容の指紋）・保存先の切り替え・モデル登録は後続タスク。
