# T-0266 ガントを単色に・粒度で幅を変える・曜日行・節目の追加

実際に描画して見た指摘への対応。

- **ガントの棒を 1 色（青）にした**。予定・完了・遅れを色で分けず、完了ぶんを同じ色の濃い塗りで重ねて示す
  （todo は薄い青、進行中は途中まで濃い、完了は全面が濃い）。遅れは表の赤い日付と今日の線で分かる。以前は
  淡い青＋濃紺の縁の二重塗りで煩かった。
- **粒度ごとに幅が変わる**ようにした。月は狭く・日は広い（1 日あたりの幅を単位ごとに決める）。以前は一定
  以上のときだけ広げていたため、月に切り替えても表が最小幅に戻って「情報量を落としたのに長いまま」だった。
- **日表示に曜日の段を足した**（年月・日にち・曜日の 3 段。土日は薄く）。
- **節目を画面から足せる**ようにした（右クリックの「節目を下に追加（◆）」）。期間ゼロの印として置く。
  定例会議など 1 点の予定も、節目か日程つきの作業として置ける。

## 受け入れ基準
- [x] ガントの棒が 1 色で、完了ぶんが同じ色の濃い塗りで乗るか。
- [x] 月・週・日で幅が変わり、月がいちばん短いか。
- [x] 日表示に曜日の段が出るか。
- [x] 右クリックから節目を足せるか（期間ゼロ・◆で出るか）。
