# T-0262 時間軸を読める形にし、単位の切り替えを実際に効かせる

「日付が表示されていない」「押しても変わらない」への対応。独立レビュー（実際にブラウザで描画して確認）で
原因が特定できた。**マークアップの検査だけでは見つからない種類の欠陥**だった。

## 直した欠陥
- **単位を切り替えると軸が真っ白になっていた**。切り替えの処理が初期の粒度を表すクラスを外しておらず、
  週・日を選ぶと「月の見出しを隠す規則」と「週の見出しを隠す規則」が同時に効いて、日付が 1 つも残らなかった。
- **既定の表示でも読めなかった**。文字 8px・地とのコントラスト 4.30:1（可読性の目安 4.5:1 未満）で、
  月の番号が 5 個出るだけだった。
- **日の目盛をそもそも作っていなかった**。「日」を押しても幅が広がるだけで、日付は増えなかった。
- 短い案件で幅の下限に張り付き、週と月が同じ見た目になっていた。

## 作り直したもの
- 時間軸を**常に 2 段**に（上＝大きい単位・下＝選んだ単位）。月＝年／月、週＝年月／`8/3w`、日＝年月／`3 4 5 …`。
  段数は切り替えても変わらない（高さが跳ねない）。文字は区間の**真ん中**に置き、10px 以上・本文の色にした。
- 「自動」を状態から外した（自動は初期値の決め方であって、利用者が選ぶ状態ではない）。初期の単位は期間の
  長さで決め、そのボタンを押した状態で出す。選んだ単位は画面をまたいで覚える。
- **まとめの行**（節・子を持つ単位）を細い帯＋両端の脚にした。全部同じ太さの帯が並ぶと階層が図から読めず
  「ただの帯」に見えていた。
- **引き伸ばす図形に文字と点を置かない**：節目の印を SVG から出して割合の位置に重ねる要素にし、線には
  太らない指定を付けた（列幅を変えると菱形が横に潰れ、線が太っていた）。
- 月表示では非稼働日の帯を出さない（1 日が細く、全面が縞模様になって棒が埋もれていた）。
- 右クリックの文言を作り直した：階層は `Lv2` の札で示し、項目は動詞始まり（上に追加／下に追加／子として追加／
  名前を変更／この行を削除…）。いちばん上の階層に足すのは行と関係が無いので見出しの「行を追加」へ移した。
- 見出しの操作を左（折りたたみ・行を追加）と右（時間軸）に分けた。時間軸は効果が出るガントの真上に置く。
- 紙では時間軸の拡大を必ず解除する（日表示のまま印刷すると右が切れていた）。
- 見出し行を縦スクロールでも残す。作業名と ID が同じ行で ID を 2 回出さない。

## 受け入れ基準
- [x] 月・週・日のどれを選んでも、軸に日付が残るか。
- [x] 日を選ぶと 1 日ごとの数字が出るか。週は `8/3w` の形か。
- [x] 上段と下段で年が二重に出ないか。
- [x] まとめの行が末端と違う描き方になっているか。
- [x] 節目・線が、列幅を変えても歪まないか。
