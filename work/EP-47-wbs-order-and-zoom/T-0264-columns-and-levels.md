# T-0264 列を意味のまとまりで括り、どの階層にも子を足せるようにする

## 直したこと
- **どの作業単位にも子を足せる**ようにした。ファイル 1 つで表していた単位は、足すときに**フォルダの単位へ
  変わる**（＝分解。親はフォルダで表す決まりに合わせる）。日程はそのとき最初の子へ移る。失敗したら分解も
  元に戻す。以前は最上位（フォルダの単位）にしか足せなかった。
- **列を意味のまとまりで括った**。見出しを 2 段にして、上の段に「作業／予定／実績」を置く。まとまりの先頭に
  強い縦罫。11 列が同じ重みで並んでいると、どこまでが予定でどこからが実績かを列名だけで読み分けることになる。
  ガントの見出しは 2 段をぶちぬくので、時間軸の 2 段と高さが揃う。
- **チーム・担当の列を消せる**ようにした（案件によってはどちらも無い）。消すとまとまりの見出しの幅も数え直す。
- **終わった行を面ごと落とす**（残っている作業に目が行くように）。
- 時間軸の日付を区間の**左**に寄せた。短すぎて文字が切れる区間にはラベルを出さない（`8/` と切れていた）。
- 「未日程」の札をやめた（日付の欄が空なのは見れば分かる。末尾の一覧は残す）。

## 受け入れ基準
- [x] ファイル 1 つの単位に子を足すと、フォルダの単位に変わって子が入るか。日程が最初の子へ移るか。
- [x] どの行にも「中に足す」先が載っているか。
- [x] 見出しが 2 段になり、まとまりの先頭に強い縦罫が入るか。
- [x] 列を消せるか。消したときにまとまりの見出しの幅が合うか。
- [x] 終わった行が面ごと落ちるか。
