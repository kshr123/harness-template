# T-0269 用語をマイルストーンに・タイトル補完・棒を単色・食い込み・集約行

実際に見た指摘（5 点）への対応。

- **「節目」→「マイルストーン」**に表記を統一（分かりにくいという指摘）。メニュー・凡例・docs。
- **タイトルの補完**：frontmatter に `title` が無い単位（この基盤の work/ に多い）は、名前が ID になっていた。
  本文の見出し `# <ID> タイトル` から ID を除いて拾うようにした。
- **棒を完全に単色**にした。予定・完了・遅れを色で分けず、進捗の二色（淡い青＋濃い青）もやめて 1 色のベタ塗り
  に。状態は行の面（白/グレー/淡ピンク）で分かる。まとめは形で区別。
- **横スクロールの食い込みを修正**：固定した作業列の上に、流れてくる他の見出しが被っていた。固定列の見出し・
  セルの重なり順（z-index）を、流れる列より手前に上げた。
- **マイルストーンの集約行**をガントの最上部に足した。全マイルストーンを時間軸上に◆で並べる（各フェーズに
  散らばる◆だけでは案件全体の節目を追えない）。定例会議もマイルストーンとして置けばここに出る。
