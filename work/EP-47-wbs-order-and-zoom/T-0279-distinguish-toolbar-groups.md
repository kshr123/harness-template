# T-0279 操作バーの群を見た目で分ける・「全て折りたたむ」の対象を分かるようにする

見た指摘：全て折りたたむ／展開と、表示の入り切りボタンの領域の違いが分からない（別物と分かるようにしたい）。
「全て折りたたむ」が何を対象にするのかも分からない。

- **3 群を種類ごとの見た目に分ける**（別物だと一目で分かるように）：
  - **階層**（行の開閉＝一度きりの操作）：行頭の三角と同じ ▾▸ を付けた文字リンク調（`.act`・濃い字・下線 hover）。
    押しっぱなしの状態は持たない（チップにしない）。
  - **表示**（列・帯の入り切り＝状態の切替）：丸いチップ（`.col`/`.lane`）。オンのとき淡い地色で塗る。
  - **時間軸**（月/週/日＝どれか 1 つ選ぶ）：ひとつながりの分割ボタン（`.seg` で枠囲み）。
  群見出し（階層／表示／時間軸）＋強い区切り線で領域を分ける。
- **「全て折りたたむ」の対象を示す**：群見出し「階層」＋行頭の三角と同じ ▾▸ で「行（階層）の開閉」だと分かる。
  文言も「全部ひらく／全部たたむ」に（対象＝行、動作＝開閉が伝わる短い語）。

## 受け入れ基準
- [x] 階層の操作が `.act`（文字リンク調・▾▸ 付き）で、表示の入り切り（チップ）と見た目が違う。
- [x] 群見出し「階層」「表示」「時間軸」と区切り線で 3 領域が分かれている。
- [x] 「全部ひらく／全部たたむ」で対象（行＝階層）が分かる。
