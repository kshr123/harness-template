# T-0263 見た目を作り直す（罫線の重み・領域の分離・3 色の配色）

独立レビュー（調査つき）の設計に沿って `_STYLE` を作り直した。

## 配色：3 色（白・黒・青）＋警告の 1 色（赤）
- **＋1 色を赤にした**。顧客向けの工程表で読み落とすと実害が出るのは「遅れ」だけで、警告は赤以外に代えが
  きかない。完了は状態の列・実績の日付・進捗の数・棒の淡さで 4 重に表しているので、色相に頼らなくてよい。
  **完了は緑を使わず**、淡い青の棒に濃紺の帯と縁を重ねて「塗り終わった」形で表す。
- 明暗どちらの地でも、本文は対比 4.5 以上・図形は 3 以上。白黒で刷ったときも「まとめ＜遅れ＜予定＜完了」の
  濃さの順が保たれる（元の配色は予定と遅れが白黒で同じ濃さになっていた）。

## 罫線と領域
- 罫線の重みを 3 段に分けた（弱＝行の区切りと日/週の格子／強＝見出しの下端・月の格子・貼り付く列の右／
  2px＝左の表とガントの境目）。すべて同じ太さだったので表計算の初期状態に見えていた。
- **時間軸に罫線を入れた**：段の間の横罫、区間ごとの縦罫（大きい単位は強い罫）。どこからどこまでが
  その月・その週なのかが読める。
- **左の表とガントを別の領域として 3 重に割った**：2px の罫・見出しの地色を変える・格子の作法を変える。
- 行の縞は入れない（折りたたむと偶奇が崩れる）。代わりに画面では行にかざしたときだけ地色を変える。

## その他
- 表の外枠を入れ物 1 枚に集め、セルの外周罫を撤去（角丸 8px）。行の高さ・文字の階調・余白を見直した。
- 棒の角丸をやめた（引き伸ばすと幅ごとに歪むため）。節目は棒の中心に載せた。
- 短すぎる区間にはラベルを出さない（月の頭で切れた半端な週が `8/` と切れて出ていた）。
- 右クリックで触っている行に印を付ける。凡例を棒と同じ見た目に揃え、まとめの帯を凡例に足した。

## 受け入れ基準

- [x] 時間軸に罫線が入り、月・週の区切りが読めるか。
- [x] 左の表とガントが別の領域として見えるか。
- [x] 色が 3 色＋1 色に収まっているか。
