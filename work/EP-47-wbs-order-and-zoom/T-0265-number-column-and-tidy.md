# T-0265 番号の列と細部を整える

実際に見て出た指摘への対応。

- **番号（No.）の列**：見出しを「WBS」から「No.」に変えた（表全体が WBS なのに列名が WBS なのが違和感）。
  番号を階層ごとに字下げ・左揃えにした（作業名と同じイメージ。番号だけで階層が読める）。
- **列オフのボタン**：取り消し線をやめ、文字を薄くするだけにした。
- **非稼働日の帯を撤去**：各週の右に灰色の帯が並んで棒より目立ち、「日付が入っていないところにうっすら色が
  ついて右に揃っている」ように見えて煩かった。週の区切りは格子線、営業日は「日数」の列で分かる。

## 受け入れ基準
- [x] 番号列の見出しが「No.」で、番号が階層ごとに字下げ・左揃えか。
- [x] 列オフのボタンに取り消し線が無いか。
- [x] ガントに灰色の帯が無いか（格子線は残る）。
