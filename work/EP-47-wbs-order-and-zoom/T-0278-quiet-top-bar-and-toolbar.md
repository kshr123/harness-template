# T-0278 上部を削る（提出先・操作説明を撤去）・操作バーを脇役の見た目にする

見た指摘：提出先（xx）は不要／操作方法が上にあるのは違和感で、無くても分かる UI にすべき／表示系のボタンが
大きく目立ち何をするか分かりにくい＝静的な提出物なのに操作が主役に見える。

- **提出先（クライアント名）の行を撤去**（上部の雑音を減らす。client を設定しても表示しない）。
- **操作の説明文を撤去**（「セルをクリックすると直せる…右クリック…Ctrl+Z…」）＝UI 自体で分かるようにする。
  編集できるセルは hover の手がかり（cursor/地色）で示す（_EDIT_STYLE）。不要になった `.hint` も削除。
- **操作バーを脇役の見た目に**：枠つきの大きなボタンをやめ、小さな薄字（枠なし・muted）にして地に沈める。
  押している・かざしたときだけ淡い地色（--sec）のチップにする（青の大ブロックは使わない）。時間軸の選択も
  同じ静かな見た目に統一。表全体（主役）を邪魔しない。

## 受け入れ基準
- [x] 上部に「提出先」が出ない（client を設定しても）。
- [x] 操作の説明文（セルをクリック…／行の操作は右クリック…）が出ない。
- [x] 操作バーのボタンが枠なしの薄字で、押下・hover のときだけ淡い地色のチップ（青ブロックなし）。
