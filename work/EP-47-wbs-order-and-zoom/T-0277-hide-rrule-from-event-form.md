# T-0277 出来事フォームから RRULE の数式を消す（誰でも使えるUIにする）

見た指摘：定例・インナーの登録フォームに出る「規則（自動で組み立て・直接書いてもよい）」の RRULE 文字列
（例 `FREQ=WEEKLY;BYDAY=WE`）が何か分からない。操作が分からないものは不要。

- RRULE の文字列を**画面から消す**（専門用語なので誰でもは使えない）。フォームは画面の操作だけで完結する：
  繰り返し「毎週／隔週／毎月第N／単発」＋曜日ボタン（複数可）＋初回＋最終（任意）。数式は裏で組み立てて
  送るだけの控え（`rule` を入力欄から素の変数に降格）。「いつ」の行に見出しを付け、単発の開催日欄に例を置く。
- **既存の出来事を直すときの復元**：数式を見せない代わりに、控えの文字列から画面の操作へ戻す＝繰り返しの種類
  （INTERVAL=2→隔週・FREQ=MONTHLY→毎月第N・他→毎週）・第N（BYDAY の頭の数字）・最終日（UNTIL）・曜日（BYDAY）。
  隠したことで編集が壊れない（ヘッドレスで weekly/WE/UNTIL の復元を実測）。

## 受け入れ基準
- [x] フォームに「規則（…）」の数式入力欄が無い（人が使う語 毎週/隔週/毎月第N/単発 は残る）。
- [x] 毎月第N で第N セレクトが出る・単発で開催日欄が出て「いつ」の行が隠れる（ヘッドレスで確認）。
- [x] 既存の出来事を直すと種類・曜日・最終日が画面へ復元される（数式を読ませずに編集できる）。
