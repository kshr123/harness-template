# T-0248 合意した計画と現在の計画の差を出す

## 作るもの
- `uv run wbs diff <参照>` … 指定した git の参照（合意時点のタグ・コミット）と現在を比べ、
  予定日を動かした単位・足した単位・消した単位を並べる。
- 変更の理由は、その日程を動かしたコミットのメッセージをそのまま添える（理由の保管場所を新設しない。
  コミットメッセージ冒頭の作業単位 ID は既存の検査が強制している）。
- 合意時点の参照を指定して、その時点の WBS をそのまま出し直せるようにする。

## 受け入れ基準
- [ ] 2 時点を比べたとき、動かした単位・足した単位・消した単位がすべて出て、動かしていない単位は出ないか。
- [ ] 差の各行に、その変更を入れたコミットが添えられているか。
- [ ] 合意時点の参照を指定して、その時点の WBS を出し直せるか。
