# T-0249 先方の様式指定に応える出力形式の枝

既定の成果物は HTML 1 つのまま（同格の成果物が 2 つ並ぶ状態を作らない）。先方が表計算の様式を
指定してくる案件のために、条件登録の枝として足す（その依存が入っている案件でだけ生える）。

## 作るもの
- 出力形式のレジストリ。既存のモデル保存形式・モデル種の条件登録と同じ流儀にする。
- 表計算の出力：階層の折りたたみ（アウトライン）、週単位の列にバー、先頭に「正本は work/。
  この表への記入は取り込まれない」と明記。
- 取り込みは作らない（クライアントの変更要望は要求層で受ける）。

## 受け入れ基準
- [ ] 依存が入っていない環境で、出力形式の一覧にその形式が出ないか（入れれば出るか）。
- [ ] 出した表を読み戻したとき、行の構成・日付が木から導いた値と一致するか。
- [ ] 既定の出力（形式を指定しない呼び出し）が HTML 1 つのままか。
