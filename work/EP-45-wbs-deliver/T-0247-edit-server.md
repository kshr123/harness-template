# T-0247 ブラウザで編集して正本へ書き戻す面を作る

参照だけでなく編集もできるようにする。書き込み先は正本ひとつ（第 2 の台帳を作らない）。

## 作るもの
- `uv run wbs edit` … 127.0.0.1 にローカルサーバを立て、表の各セルをその場で編集できる画面を出す。
  バーを掴んで動かす編集は作らない（営業日への吸着と依存の玉突きを素の JS で書くと最も検査できない塊になる）。
- 書き戻しは frontmatter の対象キーの**行置換**（設定ファイルの 1 行だけを書き換える既存の作法と同じ）。
  差分は 1 単位あたり数行に収まり、差分だけを見る独立レビューが成り立つ。
- 保存の競合検出：正本のハッシュを突き合わせて不一致なら拒否し、成功時は新しいハッシュを返す
  （返さないと 2 回目の保存が誤って拒否される）。読み込みから書き込みまでを 1 つの錠で囲う。
- 書き込み口の防御：起動ごとのトークンを本文に埋めて独自ヘッダで送らせる（URL に載せない）、
  受け取ったホスト名を検査する、一定時間触られなければ自動で終了する。

## 受け入れ基準
- [ ] 画面から日付を変えて保存すると、正本の該当行だけが書き換わるか（他の行・コメントが動かないか）。
- [ ] 保存の前に正本が別の手で書き換わっていたとき、上書きせずに拒否するか。
- [ ] 続けて 2 回保存できるか（1 回目の成功後に誤って拒否されないか）。
- [ ] トークンの無い要求・別のホスト名を名乗る要求を拒否するか。
- [ ] 検査に失敗する内容は保存されないか。
