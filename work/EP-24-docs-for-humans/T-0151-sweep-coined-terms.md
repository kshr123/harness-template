# T-0151 living docs の造語を平易な語に掃き出す

## 背景
T-0136 は用語集リンクを外す作業だったので、リンクが張られていなかった**素の造語**が本文に残っていた
（serve.md「来歴つき」「作業手順の導線」など）。書き方ルール（造語を使わず本文だけで分かる）に合わせて、
opaque な造語を平易な語へ置換する。

## やったこと（living docs のみ。docs/decisions/＝確定記録・docs/archive/＝日付メモ は対象外）
- **導線 → 案内**（人がたどり着けるリンク・案内の意）
- **門番 → 止める検査 / 処理を止めない**（blocking な検査／助言型の意。冗長な「（門番）」注記も除去）
- **棚卸し → 見直し**（定期的な見直しの意）
- **来歴 → 由来**（どこから来たか＝provenance の意）
- **ラチェット → 歯止め**（後戻り防止の意）
- 金メッキ（1 箇所）は T-0136 で既に平易な説明つき＝そのまま。

## 残した語（意図的）
`正本`・`案件`・`入口`・`関門`・`昇格`・`歩く骨組み`は、各文書の初出で平易な一文説明がある（T-0131/0132/0136 で
付与済み）ため、素で放置していない。これらは短く繰り返し使う中核語で、全置換すると本文が冗長になり読みにくく
なるので、初出で説明し以降は短い語で使う方針（＝「造語を bare で使わない」を満たす）。さらに徹底したい場合は
別タスクで再検討する。

## 受け入れ基準
- `uv run verify` 全成功（doclint がリンク整合を検査＝置換で参照を壊していない）。
- living docs に opaque な造語（導線/門番/棚卸し/来歴/ラチェット）が素で残っていない。

## 触ってよい範囲
`README.md`・`AGENTS.md`・`docs/*.md`（decisions/・archive/ を除く）・`.claude/skills/*/SKILL.md`・この item.md。
