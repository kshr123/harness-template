# DoD（完了の定義）

タスクが「完了（done）」と言えるのは、次をすべて満たすときだけ。自己申告では完了にしない。

- [ ] `uv run verify` が緑（孤児検出＋STATUS 一致＋ruff＋mypy＋pytest）。
- [ ] 受け入れ基準（タスク MD の「受け入れ基準」）を満たす。
- [ ] 範囲外を変更していない（変更したなら別タスク／変更管理）。
- [ ] `uv run status` で STATUS.md が最新。
- [ ] 学び（friction 含む）があれば `learnings.md` に記録した。
- [ ]（チームモード）PR が CI 緑＋レビュー承認でマージされた。
