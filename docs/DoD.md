# DoD（完了の定義）

タスクが「完了」と言えるのは、次をすべて満たすときだけ。自己申告では完了にしない。

- [ ] `uv run verify` にすべて成功する（参照チェック＋STATUS 一致＋ruff＋mypy＋pytest）。
- [ ] 受け入れ基準（タスク本文の「受け入れ基準」）を満たす。
- [ ] 頼まれた範囲の外を変更していない（変更したなら別タスク／変更管理にする）。
- [ ] `uv run status` で STATUS.md が最新になっている。
- [ ] 気づき（使いにくかった点を含む）があれば `learnings.md` に記録した。
- [ ]（チームで進める場合）PR が CI にすべて成功し、レビュー承認を得てマージされた。
