# DEM-002：クライアントに見せられる WBS とスケジュール（ガント）が欲しい

## 要求（クライアントの言葉で・原文に近く）
案件の計画をクライアントと合意し、定例会議で進捗を報告できる WBS が欲しい。WBS 番号・タスク（3〜4 階層で
折りたためる）・担当チーム・担当者（複数）・状態・予定（開始・終了・日数）・実績・ガントが要る。土日祝を
除いた営業日で数えたい。参照できるだけでなく、編集もできること。

## 背景の業務課題（なぜこの要求が出るか）
As-Is：作業単位の木（`work/`）に日程はあるが、クライアントに見せられる形が無い。提案・定例・最終報告の
たびに手で表を作り直しており、作った表と実態がすぐ食い違う。
To-Be：正本 1 つから生成し、生成し直せば必ず実態と一致する。合意した版と現在の差を説明できる。
