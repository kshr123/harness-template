# DEM-001：コンサル・DS・エンジニアの3者に必要なものが揃ったプロジェクトが欲しい

## 要求（クライアントの言葉で・原文に近く）
案件を回すコンサル・データサイエンティスト・エンジニアの3者が、それぞれ必要な道具・成果物・検証を1つの
プロジェクトで得られるようにしたい。案件を重ねるほど強くなること（前案件の改良が次に効くこと）も重要。

## 背景の業務課題（なぜこの要求が出るか）
As-Is：案件ごとに基盤を作り直し、正しさの担保も属人的。To-Be：複製すれば3者の土台が揃い、完了は検証で
機械的に確定し、改良が本体へ還流して蓄積する。

## 却下/保留の理由（rejected・deferred のときは必須）
（なし）
