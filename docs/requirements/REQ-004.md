# REQ-004：データサイエンスの実験ループ（ローカル完結）

## 内容（何を満たすか）
基盤（固定分割・評価・テーブル定義・保存＝検証済み）の上に、実験の一巡を載せる。特徴量（fit/transform で漏れ防止）→学習（モデル差し替え可・seed明示）→評価（指標・閾値で合否）→結果記録→モデル登録（ローカル台帳）を、ネットワーク・サーバ無しで回せるようにする。参考リポ（`draft/reference/ml-competition-template-main`）の考え方を、私たちの流儀（polars・保存＝検証済み・seed明示・固定分割が土台）に合わせて取り込む。

## 受け入れ基準（どうなったら満たすか）
- [ ] 特徴量パイプライン（`fit_transform` 第一級・行数検証・`describe`）が漏れなく train→valid を変換できる。
- [ ] 分割をインデックス対のリストとして学習系に渡せる（固定分割＝要素1・CV＝要素k）。fold 割当は split 層のテーブルに保存する。
- [ ] 学習はモデル差し替え可（まず scikit-learn）・seed は明示引数。target 変換の往復に対応。
- [ ] 評価が指標を返し、閾値を valid/OOF で選び、設定の閾値で合否を判定する。
- [ ] モデル登録はローカル台帳（マニフェスト・指紋・上書き拒否）で、保存＝記録済みだけ。
- [ ] 実験 E-0001 が `--test` スモークで端から端まで通り、`uv run verify` に含まれる。結果（指標・設定・データ指紋・結論）が記録される。
