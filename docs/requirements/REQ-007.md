# REQ-007：遅れが問い合わせなしで分かり、日程の無い単位が黙って消えない

## 内容（何を満たすか）
生成時点の日付（今日の線）が描かれ、「予定終了を過ぎて未完」の単位が他と視覚的に区別される。定例会議で
遅延の有無の確認に口頭の補足を要さない。あわせて、日程を持たない単位は描画から黙って消えず「未日程」として
明示的に列挙する（0 件の描画で成功しない＝空振りで緑にならない）。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] 予定終了が生成日より過去で状態が done でない単位を含む木から生成したとき、その単位だけが遅延の印を持つか。
- [ ] 予定終了を過ぎていても done の単位・予定終了が未到来の単位に、遅延の印が付かないか。
- [ ] 日程あり 3 件・日程なし 2 件の木から生成したとき、出力に 5 件すべての ID が現れるか（未日程 2 件が未日程の区画に居るか）。
- [ ] 日程を 1 件も持たない木からの生成は、空のガントを黙って出さずに失敗するか。
