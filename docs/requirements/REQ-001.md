# REQ-001：作業単位の木から進捗を自動算出し、完了を検証で確定する

## 内容（何を満たすか）
`work/` の作業単位の木をたどって進捗を自動で出し、ID の重複や depends_on の参照エラー、完了↔検証の欠落を機械的に検出する。完了は共通の検証コマンドの成功でのみ確定する（自己申告では完了にしない）。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] `uv run status` が進捗（`STATUS.md`）を作り直す。
- [ ] `uv run task-lint` が、ID の重複・depends_on の参照エラー・done なのに `verified_by` が空／指す先が無い、を失敗にする。
- [ ] `uv run verify` にすべて成功して初めて完了にできる。

- EP-01 / T-0001
