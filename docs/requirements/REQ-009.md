# REQ-009：WBS は参照できるだけでなく編集でき、書き込み先は正本ひとつである

## 内容（何を満たすか）
WBS は画面で見るだけでなく、その場で予定日・担当・状態を直せること。編集の入口が何であれ、書き込み先は
作業単位の正本ひとつに限る（画面の側に状態を溜めない・第 2 の台帳を作らない）。保存の前に正本が別の手で
書き換わっていたときは、上書きせずに拒否する（黙って巻き戻さない）。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] 画面から日付を変えて保存したとき、正本の該当箇所だけが書き換わるか（他の行・コメントが動かないか）。
- [ ] 保存の直前に正本が別の手で書き換わっていた場合、保存は拒否されるか。
- [ ] 検査に失敗する内容は保存されないか。
- [ ] 編集の入口を使わずテキストを直接直しても、同じ結果になるか（入口が違っても正本が 1 つであること）。
