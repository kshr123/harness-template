# REQ-006：提出物は単一ファイルで独り歩きでき、由来が刻まれている

## 内容（何を満たすか）
クライアントに渡す WBS は、ネットワーク・外部リソース・実行環境なしで開ける単一ファイルであること
（先方の担当者が社内へそのまま転送でき、印刷にも耐える）。どの時点の正本から出たかを後から照合できるよう、
生成物には由来（コミット・生成日時・作業単位の木の fingerprint）を刻む。作業ツリーに未コミットの変更が
あるときは既定で生成を拒否し、明示の下書き指定のときだけ下書きと分かる形で出す。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] 生成ファイル 1 つだけを別の場所へ写して開いたとき、全内容が表示されるか（外部リソースへの参照が本文に 0 件か）。
- [ ] 未コミットの変更がある状態で既定の生成を試みたとき、失敗するか（成功してしまえば刻んだコミットが嘘になる）。
- [ ] 下書き指定で生成したとき、下書きであることが生成物の見た目から分かるか。
