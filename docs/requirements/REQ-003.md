# REQ-003：新構造の実装（置き場の切り替え・調査・課題・データ管理）

## 内容（何を満たすか）
設計文書（`03_設計` の新構造）に実装を合わせる。置き場を設定で切り替えられるようにし、作業単位に調査を加え、発見された問題を課題として登録・追跡でき、データはテーブル定義に照らして検証してから保存できるようにする。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] `.harness/config.toml` でデータ・課題・メタデータの置き場を切り替えられる（層ごとの上書きを含む）。
- [ ] 作業単位に調査（investigation）があり、done の調査は結論の記録を検査で要求する。
- [ ] 発見された問題を課題として登録し、対処時にタスク・調査へ昇格でき、整合を検査する。
- [ ] テーブル定義に照らして検証したデータだけを保存できる。
- [ ] 各段階で `uv run verify` にすべて成功する。
