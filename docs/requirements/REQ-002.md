# REQ-002：データサイエンスの基盤（固定分割・データ漏れ防止・評価の仕組み）

## 内容（何を満たすか）
共通の開発基盤の上に、データサイエンス固有の基盤を載せる。データを固定分割し、最終評価用のデータを学習・調整に使わないこと（データ漏れの防止）を機械的に保証し、評価が指標を返して設定の閾値で合否を判定できるようにする。特徴量の計算は共有コードに置き、単体テストの対象にする。

## 受け入れ基準（どうなったら満たすか。確かめられる形で書く）
- [ ] 合成データが決め打ちの種から再現でき、固定分割が同じ種で必ず同じ結果になる。
- [ ] 学習・調整用と最終評価用の分割に重複が無いことをテストが保証する。
- [ ] 評価が指標を返し、設定ファイルの閾値で合否（成功/失敗）を返す。
