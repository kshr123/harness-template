# 要件：demo（ハーネス自身の構築）

## この文書の位置づけ
- 憲章（`charter.md`）の目的・スコープを、満たすべき個別の要件に分解したもの。
- 各要件は一意の ID（`REQ-xxx`・再利用しない）と、確かめられる受け入れ基準を持つ。
- 実装の作業単位（`work/…`）は frontmatter の `requirements` でこの ID を参照する（要件↔作業↔検証のつながり）。

## 要件一覧

### REQ-001：作業単位の木から進捗を自動算出し、完了を検証で確定する
- 内容：`work/` の作業単位の木をたどって進捗を自動で出し、ID の重複や depends_on の参照エラー、完了↔検証の欠落を機械的に検出する。完了は共通の検証コマンドの成功でのみ確定する。
- 種別：機能
- 受け入れ基準：
  - [ ] `uv run status` が進捗（`STATUS.md`）を作り直す。
  - [ ] `uv run task-lint` が ID の重複・depends_on の参照エラー・done なのに verified_by が無い／指す先が無い、を失敗にする。
  - [ ] `uv run verify` にすべて成功して初めて完了にできる（自己申告では完了にしない）。
- 対応する作業単位：EP-01 / T-0001
